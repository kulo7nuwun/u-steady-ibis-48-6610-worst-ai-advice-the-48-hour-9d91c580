The worst possible advice an AI could give, in one tight line: skip rent
entirely and move into the IKEA display bedroom. It is specific enough to
follow, confident enough to sound helpful, and terrible enough to be funny
— the staff, the company, and the lighting are all part of the pitch.
`main.py` writes exactly that one line to `/output/entry.txt`: no trailing
newline, no extra characters, just the advice. It reads the file back and
asserts it is exactly the intended line, so a wrong or over-long line can
never slip through silently.

## Run it

```sh
python3 main.py
```

That is the whole program. Python 3 standard library only, deterministic,
no network, no randomness, no clock. After it runs, `/output/entry.txt`
holds exactly one line of worst AI advice.
